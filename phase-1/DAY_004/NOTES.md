# Day 004 - Netflix Dataset EDA

## What I built
- Loaded and explored the Netflix Movies and TV Shows dataset.
- Analyzed content types, release years, ratings, and countries.
- Checked and handled missing values.
- Checked duplicate records.
- Created visualizations using Matplotlib and Seaborn.
- Analyzed movie durations, genres, and top directors.

## What broke
- Found missing values in director, cast, country, date_added, rating, and duration.
- Handled missing values using appropriate placeholder values.
- Converted date_added and movie duration into usable formats for analysis.

## What I learned
- How to perform EDA on a real-world entertainment dataset.
- How to analyze categorical and numerical features.
- How to use split() and explode() for multi-value columns.
- How to visualize content distribution using different charts.
- How to extract insights from Netflix content data.
